Rebooting into WiFi setup mode…

  1. Wait a few seconds for the device to restart.
  2. On this phone/laptop, join the device's own WiFi network (its name starts with Piste_).
  3. Then tap: 192.168.4.1/wifi

The link won't load until step 2 is done -- this page has no way to switch your WiFi network for you.
